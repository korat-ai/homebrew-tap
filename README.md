# homebrew-tap

Homebrew tap for [korat](https://github.com/korat-ai/korat-mcp-hub).

## Status

Stub Formula. Do **not** install yet — `brew install korat-ai/tap/korat` will
hard-fail until the first real release lands and bumps the Formula.

The Formula is auto-bumped by korat-mcp-hub's `release.yml` workflow on every
tag push. See `Formula/korat.rb` for current state.

## Once announced

```bash
brew tap korat-ai/tap
brew install korat
korat version
```
